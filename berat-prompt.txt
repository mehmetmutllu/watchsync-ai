WatchSync AI projesinde Junior Frontend Developer olarak çalışıyorum.

İLK KURULUM ADIMLARI — Aşağıdakileri sırasıyla yap:
1. Repoyu klonla: git clone https://github.com/mehmetmutllu/watchsync-ai.git
2. Klasöre gir: cd watchsync-ai
3. develop branch'ine geç: git checkout develop
4. Git kimliğimi ayarla: git config user.name "Berat" ve git config user.email "[BURAYA E-POSTAN]"
5. Frontend bağımlılıklarını kur: cd frontend && npm install
6. Frontend'i çalıştır: npm run dev
7. Tarayıcıda http://localhost:3000 aç ve çalıştığını doğrula

NOT: Backend (API) Docker ile Mehmet'in makinesinde çalışıyor.
Eğer backend'e erişemiyorsan Mehmet'e sor.
Backend olmadan da frontend build alabilir ve UI geliştirme yapabilirsin.
