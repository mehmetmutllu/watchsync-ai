WatchSync AI projesinde Junior Frontend Developer olarak çalışıyorum. Mac kullanıyorum.

İLK KURULUM ADIMLARI — Aşağıdakileri sırasıyla yap:

ADIM 1 — Gerekli yazılımları kontrol et:
- git --version (yoksa: brew install git)
- node --version (Node.js 20+ gerekli, yoksa: brew install node)
- docker --version (yoksa: https://docs.docker.com/desktop/setup/install/mac-install/ adresinden Docker Desktop for Mac kur)
- Docker Desktop uygulamasının açık ve çalışır durumda olduğunu kontrol et

ADIM 2 — Repoyu klonla ve ayarla:
1. git clone https://github.com/mehmetmutllu/watchsync-ai.git
2. cd watchsync-ai
3. git checkout develop
4. git config user.name "Berat"
5. git config user.email "[BURAYA E-POSTAN]"

ADIM 3 — Backend'i Docker ile kur (Laravel + MySQL + Redis):
1. cd backend
2. cp .env.example .env
3. docker compose up -d   (ilk seferde image build eder, 5-10 dk sürebilir)
4. docker compose exec laravel.test composer install
5. docker compose exec laravel.test php artisan key:generate
6. docker compose exec laravel.test php artisan migrate --seed
7. Doğrulama: curl http://localhost:8000/api/auth/login -X POST -H "Content-Type: application/json" -H "Accept: application/json" -d '{"email":"demo@watchsync.ai","password":"password"}'
   → Token döndüyse backend çalışıyor

ADIM 4 — Frontend'i kur:
1. cd ../frontend
2. npm install
3. npm run dev
4. Tarayıcıda http://localhost:3000 aç
5. Demo giriş: demo@watchsync.ai / password

ÖNEMLİ NOTLAR:
- MAMP'ı kapatabilirsin, ona gerek yok. Docker her şeyi hallediyor.
- Docker Desktop açık olduğu sürece backend çalışır.
- Eğer Mac'i kapattıysan, açtığında Docker Desktop otomatik başlar ve "docker compose up -d" ile backend tekrar ayağa kalkar.
- Port çakışması olursa (MAMP 3306 kullanıyordur): MAMP'ı kapat veya .env dosyasında FORWARD_DB_PORT=3308 yap.
